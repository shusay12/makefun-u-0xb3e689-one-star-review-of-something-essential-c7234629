## The review

> Wi-Fi works perfectly until the one moment I actually need it, then pretends it has never met me. One star.

## The entry

`main.py` (Python 3.13, stdlib only, no network, no randomness) writes that
one line to `/output/entry.txt` — deterministically, the same bytes on
every run. The line is 107 characters, inside the 160-character gate.
A judge model compares reviews two at a time, weighing first whether it
is a deadpan one-star review of an everyday essential, then the sharpest
true grievance, then the deadpan hold, then a turn in the last few words,
then tightness. The grievance here is Wi-Fi's: it never fails while idle,
it fails at the one moment it matters. The deadpan holds throughout, and
the sting turns in the last few words — the network does not merely drop,
it "pretends it has never met me". One joke, told cleanly. The top five
split $5.
